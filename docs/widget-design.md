# Виджет

Редакция от 2026-11-20. Продолжает `docs/architecture.md`: оверлей расширения (content script, shadow root, Alpine CSP + TSX).

## Состав

- **Beta Lupus Regina** — лицо виджета, фиксированный угол страницы (справа внизу). Молча показывает эмоцию, звука нет.
- **Подсказка** — отдельное всплывающее окно `position: fixed` в другом углу (слева внизу): вопрос `ask`, жесты, кнопки мыши, таймаут.
- **Индикатор камеры** — красная точка с именем плагина на аватаре, пока камера включена. Esc или клик по нему выключает камеру.

## Персонаж

Лицо рисуется без рта. Глаза и брови — SVG-вариант на каждую эмоцию, рот — отдельный `<path>` одной линией
(`stroke`, без заливки), который подменяется по эмоции. Так эмоций можно добавлять без перерисовки лица.

| Эмоция     | Источник                     | Рот (`d`, один кубический сегмент, viewBox `0 0 100 40`) |
| ---------- | ---------------------------- | -------------------------------------------------------- |
| `neutral`  | `NEUTRAL`; ожидание жеста    | `M30 20 L70 20`                                          |
| `happy`    | `HAPPY`; ответ принят        | `M30 16 Q50 32 70 16`                                    |
| `sad`      | `SAD`; ошибка                | `M30 26 Q50 12 70 26`                                    |
| `angry`    | `ANGRY`                      | `M30 24 L70 18`                                          |
| `contempt` | `CONTEMPT`                   | `M30 22 Q55 22 70 14`                                    |
| `disgust`  | `DISGUST`                    | `M30 22 Q40 14 50 22 T70 22`                             |
| `fear`     | `FEAR`                       | `M34 24 Q42 20 50 24 T66 24`                             |
| `surprise` | `SURPRISE`                   | `M42 22 C46 10 54 10 58 22`                              |
| `focused`  | прогрев «смотрю…»            | `M36 20 L64 20`, взгляд на камеру                        |
| `confused` | `confused` по жесту, таймаут | `M32 22 Q42 16 50 22 T68 22`                             |

Выбор эмоции из пакета метрик SDK: берётся `expression` с наибольшей оценкой; если максимум ниже порога
(стартово 40 %), остаётся прежняя. Смена с плавным переходом рта (`d` анимируется 150 мс), без мигания:
не чаще раза в 300 мс. Служебные эмоции (`focused`, `confused`, `happy` на «принят», `sad` на ошибку) задают фаза
виджета и жесты и перекрывают выражение пользователя.

## Фазы

| Фаза                | Beta             | Подсказка                                                                                      |
| ------------------- | ---------------- | ---------------------------------------------------------------------------------------------- |
| `idle`              | не показана      | не показана                                                                                    |
| `warmup` (3–4 с)    | `focused`        | вопрос и кнопки сразу, «смотрю…»                                                               |
| `listening`         | по выражению SDK | вопрос, жесты (`🙂 улыбка`, `🤔 недоумение`), кнопки, отсчёт                                   |
| `accepted` (~0,6 с) | `happy`          | выбранный вариант, затем скрывается                                                            |
| `timeout`           | `confused`       | «Не разобрала, нажмите ответ», камера уже выключена                                            |
| `error`             | `sad`            | человеческая подсказка по коду SDK (`kNoFaceFound` → «Не вижу лицо», `kTooDark` → «Темновато») |

Таймаут `ask` считается от начала `listening`, а не от показа.

## Реализация

- `apps/wxt/src/components/`: `Beta.tsx` (лицо + рот), `HintPopup.tsx`, `CameraBadge.tsx`.
- Состояние одним объектом: `{ phase, emotion, question, options, deadlineAt, pluginName }`; background шлёт
  сообщения `phase` и `emotion`, оверлей только рисует.
- Стили внутри shadow root; светлая/тёмная тема по `prefers-color-scheme`; без внешних шрифтов и ресурсов.
- Доступность: подсказка — `role="dialog"`, `aria-live="polite"`; любое действие доступно мышью и клавиатурой;
  `prefers-reduced-motion` отключает анимацию рта.

## Интерфейс расширения

Четыре экрана. Оверлей на странице описан выше (Beta, подсказка, индикатор камеры); ниже остальные три.

### 1. Popup (иконка расширения)

Сверху вниз:

1. **Статус сервера** — точка (зелёная/серая) и текст «Сервер: на связи» / «Сервер недоступен, запустите `bun run dev`».
2. **Камера** — состояние («Выключена» / «Включена плагином „Оценка сервиса“») и кнопка «Выключить камеру».
3. **Пауза** — если камеру держит always-плагин, под кнопкой «Выключить камеру» подпись «Paused on this page until it is reloaded» после нажатия; тумблера режима нет.
4. **Кнопка «Плагины»** — открывает страницу плагинов.

### 2. Страница плагинов (options)

Одна колонка, сверху вниз:

1. **Баннер прав** (только если `userScripts` недоступен): «Разрешить пользовательские скрипты» — Chrome: шаги включения в
   `chrome://extensions`; Firefox: кнопка `permissions.request()`. Пока баннер виден, остальное неактивно.
2. **Зона установки**: область перетаскивания и кнопка «Выбрать файлы» (`<input type=file multiple>`).
3. **Список установленных плагинов**, строка на плагин:
   - название и автор (из заголовка `==Reaction==`);
   - сайты (`@match`) чипами;
   - режим камеры: «по событию» или «всегда»;
   - сигналы (`smile`, `nod`, …) чипами;
   - тумблер вкл/выкл, кнопки «Код» и «Удалить».
4. **Пустое состояние**: «Плагинов нет», ссылка на `reactions.d.ts` и «Промпт для агента: напиши плагин».

Кнопка «Код» раскрывает под строкой код плагина (только чтение, моноширинный шрифт).

### 3. Окно установки (модалка поверх страницы плагинов)

Открывается после выбора файла, до записи в `storage.local`:

1. Название, автор, версия.
2. «Работает на сайтах»: список `@match`.
3. «Камера»: «включается по событию страницы» или «включена, пока страница открыта и в фокусе» (красным) и фраза согласия.
4. «Использует сигналы»: список жестов и что они значат.
5. Код плагина полностью, с прокруткой.
6. Кнопки «Установить» и «Отмена». Если заголовок невалиден — вместо 2–6 причина отказа и только «Закрыть».

### 4. Разрешение камеры (разово)

- Chrome: страница расширения «Камера» с кнопкой «Разрешить камеру» (разрешение запоминается, offscreen-документ работает дальше).
- Firefox: вкладка «Камера» с превью без записи, остаётся открытой, пока нужен захват.
- Появляется только при первом включении камеры или если разрешение отозвано.

### Где что выводится

| Что                                    | Где                                            |
| -------------------------------------- | ---------------------------------------------- |
| Вопрос `ask`, жесты, кнопки, отсчёт    | Подсказка (оверлей, слева внизу)               |
| Эмоция по ответу SDK                   | Beta (оверлей, справа внизу)                   |
| Камера включена, имя плагина           | Индикатор на Beta; текст в popup               |
| Подсказки по ошибкам SDK               | Подсказка, фаза `error`                        |
| `ctx.toast`                            | Короткая строка сверху справа, 3 с             |
| Статус сервера                         | Popup                                          |
| Установка, список, код, согласие       | Страница плагинов и окно установки             |
| Права `userScripts`, разрешение камеры | Баннер на странице плагинов; страница «Камера» |
