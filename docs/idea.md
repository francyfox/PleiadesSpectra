# Идеи для Presage SmartSpectra Challenge

Кратко: одна-две строки на идею. Статусы: `рассматриваем` · `отклонено` · `выбрано`. Дедлайн: 2026-11-22.
Оценка: SDK·UX·оригинальность·срок·безопасность по правилам, каждое 1–5, сумма из 25.
Требования: персонаж из Плеяд (горничные alpha/beta/gamma/delta…), отсылка к Pleiades, желательно веб.

1. **Беззвучные команды сайту по губам.** `отклонено`: нет lip-reading в SDK, не успеть за 4 дня. **Оценка: 14.**
2. **Чатбот магазина, снижающий давление.** `отклонено`: риск «манипуляции», плохо виден на видео. **Оценка: 13.**
3. **Подтверждение дыханием для опасных действий агента.** `отклонено`: Proof of Breath уже есть. **Оценка: 16.**
4. **UX-карта эмпатии** (expression + пульс/EDA + события сайта + интервью). `рассматриваем`: похоже на Ad Pulse Lab, персонаж притянут. **Оценка: 15.**
5. **Горничная-ассистент с неявным feedback** (expression/пауза после ответа → переформулирует в своём стиле). `рассматриваем`, фаворит: аналогов нет; риск — expression шумный. **Оценка: 18.**
6. **Виджет, укорачивающий ответы при перегрузке.** `отклонено`: похоже на CalmDesk/ZenDev. **Оценка: 16.**
7. **Stay Cool** (вопросы в «горячем кресле», пульс вырос — штраф/выпивка). `отклонено` в исходном виде: занято (CalmRR, Poker Face AI Detective, Cool Vitals, L), пульс за секунды не ловится, алкоголь + «детектор лжи» плохо для жюри. Спасение: вопросы задаёт горничная Плеяд (маленькая модель), непрерывный замер раунда. **Оценка: 14.**
8. **Оценка лицом вместо шкалы 1–10** (SVG-персонаж повторяет выражение, пользователь жмёт «Отправить»; позже лицо → emoji). `рассматриваем` как финал идеи 5, не отдельно: отдельный опрос с камерой не пройдёт по конверсии, использует только `expression` (то же даёт MediaPipe бесплатно), мультяшное зеркало уже есть (LumiPulse #70, Breathless Reef #24). Кролика Rayman/Rabbids не брать (чужой персонаж), рисовать горничную Плеяд. Ветка «лицо → emoji» отклонена: 8 классов, Animoji/Memoji уже есть. **Оценка: 20 (вместе с 5; отдельно 18).**
9. **Сигналы как факты GOAP** (`talking`, `expression`, тренд пульса → предусловия действий горничной: не перебивать, предложить проще, сделать паузу). `рассматриваем` как часть 5: глубокая связь с Pleiades, несколько сигналов; риск — интеграция с оркестратором за 3 дня, близко к Bio-Sync Operator OS (#33). **Оценка: 18.**
10. **Скоупы согласия на сигналы для агента** (как OAuth: «горничная видит улыбку — да, пульс — нет», индикатор, отзыв в один клик). `рассматриваем` как слой для 5+8: попадает в «Thoughtful Real-World Use» и в consent-раздел; сам по себе не приложение, а UI. **Оценка: 20 (как слой).**
11. **Визуальная новелла с горничной** (выбор реплики выражением лица, «доки-доки»-шкала от живого пульса в ключевых сценах). `отклонено`: сложно сделать за 3 дня (сценарий, арт, ветки), почти не продвигает Pleiades; новелл в реестре нет; риск — сценарий и арт за 3 дня, пульсу нужны ~10–20 с на сцену, «свидание с горничной» может выглядеть кринжово — делать чаепитие/дружбу. **Оценка: 20.**
12. **Горничная-соведущая для стрима** (оверлей OBS: пульс/улыбка стримера, реплики маленькой модели «чат, у него 120!»). `рассматриваем`: реальный спрос (Pulsoid, но с часами); риск — пульс публично в эфире, демо требует настройки OBS. **Оценка: 18.**
13. **Фотобудка-пурикура** (горничная снимает, только когда улыбка настоящая, на фото штамп с пульсом). `рассматриваем`: быстро сделать; пересекается с The Living Darkroom (#2) и Pulse Postcards (#57). **Оценка: 19.**
14. **Подбор музыки по пульсу.** `отклонено`: занято (PulseTones #23, Aura #11, PulseVerse #88), в реальном мире есть у беговых приложений (RockMyRun, Weav); пульс за 10–20 с не годится для быстрой смены трека. Остаток: темп фоновой музыки в новелле (11) следует за пульсом. **Оценка: 13.**
15. **WebMCP-пакет «сигналы пользователя»** (сигналы SDK как WebMCP-инструменты `is_talking`, `get_expression`, `get_pulse_trend`, каждый со своим согласием; горничная Pleiades — демо-клиент). `рассматриваем` как основа под 5+8+10, не отдельно (сам по себе не продукт, на конкурсе слабо); полезен любому агенту на странице, продвигает Pleiades/WebMCP, совпадает с линией Presage (MCP, коннекторы); риск — на видео суховато, близко к SignalSpec (#104). **Оценка: 20.**
16. **Визуальный VAD для голосового виджета** (`talking` с камеры включает микрофон горничной вместо кнопки; шум ТВ не срабатывает). `рассматриваем`: реальная боль голосовых ботов, аналогов в реестре нет; риск — `talking` один сигнал, задержка неизвестна, камера + микрофон сразу. **Оценка: 19.**
17. **Проверка «живой человек» для чата** (горничная просит моргнуть и улыбнуться, плюс наличие пульса → пускает в чат без капчи). `отклонено`: обход виртуальной камерой с записью видео пишется за ~10 мин, смысл капчи теряется; реальная проблема спама в виджетах; риск — повтор видео подделывает пульс, недоступно людям, которые не могут улыбнуться, звучит как биометрия. **Оценка: 19.**
18. **Реакции лица как датасет для маленькой модели** (лицо после ответа → пары «лучше/хуже» для дообучения, экспорт локально). `рассматриваем`: оригинально, прямо про маленькие модели; риск — само обучение за 3 дня не показать, `expression` шумный. **Оценка: 17.**
19. **AI-арена моделей с горничной-ведущей** (ответы двух моделей показываются по очереди, во время чтения пишется `expression`, затем голос — лицом или кликом; итог — карта «лицо vs клик» по моделям, экспорт пар предпочтений). `рассматриваем`, фаворит: объединяет 4 (карта эмпатии), 18 (датасет) и малые модели Pleiades; в реестре арен нет. Пульс не берём (затратно). Вместо готовых эмоций — свои микрореакции по landmarks (брови, уголки губ). Риски: браузерного SDK нет, нужен Node-мост; число точек landmarks не документировано; взгляда нет — ответы только по очереди, не рядом; при чтении лицо в основном NEUTRAL; пульс медленный, годится только для сессии целиком. **Оценка: 20.**
20. **Виджет «лицо как пульт» + агент через WebMCP** (вызов подмигиванием, кивок/покачивание = да/нет, наклон = скролл, оценка лицом; агент Pleiades делает сложные действия на сайте, пользователь только подтверждает). `рассматриваем`, фаворит: связная история «узкий ввод лицом + агент = полный контроль сайта», сильна для «Thoughtful Real-World Use» (руки заняты/моторные ограничения). Риски: браузерного SDK нет — нужен локальный мост, «любой сайт» без установки не выйдет; скролл головой = Glimra (#68), моргание-коммуникация = OnBlink (#43), Hear Me (#92), #77; Морзе медленный и занят — не брать; арена — отдельный продукт, не смешивать; подмигивание одним глазом только по landmarks. **Оценка: 21.**
21. **Веб-флейта на дыхании** (выдох → звук флейты, возможно ноты лицом). `отклонено`: SDK работает только с видео (камера, файл, кадры), других датчиков нет; дыхание даёт `upper_trace`/`lower_trace` (движение груди/живота, фаза вдох-выдох есть), но задержка не документирована и `stable` наступает не сразу, амплитуды нет; дыхание как контроллер занято (PulseTones #23 — тоже веб-камера, вдох открывает фильтр; Kuudu #63, Glassbreath #3, Breathblown #71, Breath Actor #82); браузерного SDK нет; с Pleiades не связано. **Оценка: 13.**
22. **«Tampermonkey для лица»** (расширение: жесты/реакции из SDK запускают пользовательские скрипты `defineReaction(...)`, скрипты пишет любой агент; демо — всплывашка оценки сервиса лицом и скролл). `рассматриваем`, фаворит, развитие 20 без своего агента и без MCP как обязательной части. В реестре скриптуемых жестов нет; скролл головой — Glimra (#68), моргание-команды — OnBlink (#43), Hear Me (#92). Риски: в MV3 нельзя `eval` — нужен `chrome.userScripts` (пользователь включает «Allow User Scripts»); код от агента выполняется со всеми правами страницы — показывать скрипт и сайты до включения; жестов мало (кивок, покачивание, наклон, улыбка, недоумение, речь), подмигивание только по landmarks. Дополнение: камера по умолчанию включается только по событию страницы (`ctx.ask()` в модалке оценки) и выключается после ответа; постоянный режим — опция для жестов вроде скролла. Риск: прогрев (камера + старт SDK + калибровка) — секунды, не замерено. **Оценка: 19.**
